# Budget Tracker

A personal budget tracker built with React. This project is designed to make it easier to keep track of income, expenses, and everyday transactions through a simple and clean interface.

## Getting Started

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd midterm-project-webdvt
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project can also be checked and built with:

```bash
npm run lint
npm run build
npm run preview
```

## Routes

```text
/                       Dashboard
/add                    Add Transaction
/transaction/:id        Transaction Details
/summary                Summary
```

## Notes

This is a frontend project, so the transaction data is saved locally in the browser.

The project was created to practice building a React application with reusable components, page navigation, forms, and a responsive user interface.
